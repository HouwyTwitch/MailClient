# Корпоративная почта для Linux (Astra Linux SE)

Версия для Linux собирается из ветки `astra-linux`. Почтовая часть та же, что в версии для Windows:
Exchange (EWS), IMAP/SMTP, синхронизация, кэш, кодировки, обработка ошибок. Интерфейс написан на Avalonia,
письма показываются и пишутся во встроенном WebKitGTK.

## Установка

Пакет `mailclient_<версия>_amd64.deb` собирает CI (GitHub Actions, workflow `linux`). Он лежит в артефактах
сборки, а для тегов `vX.Y.Z` — в GitHub Release.

```bash
sudo apt install ./mailclient_1.0.0_amd64.deb
```

`apt` сам поставит зависимости из репозиториев дистрибутива. Программа ставится в `/opt/mailclient`,
запускается командой `mailclient` или из меню («Сеть → Корпоративная почта»). Она регистрируется как
обработчик ссылок `mailto:`.

Каждая сборка проверяется в CI так: пакет ставится в чистые контейнеры Debian 12 (основа Astra Linux 1.8)
и Debian 10 (основа Astra Linux 1.7), затем программа запускается.

| Пакет | Зачем |
|---|---|
| `libwebkit2gtk-4.1-0` или `libwebkit2gtk-4.0-37` | Просмотр HTML-писем и редактор с форматированием. Без него письма показываются текстом, а пишутся без форматирования |
| `libsecret-tools` | Хранение паролей в хранилище ключей рабочего стола. Без него пароль хранится в зашифрованном файле, доступном только пользователю |
| `libnotify-bin` | Уведомления о новых письмах |
| `xdg-utils` | Открытие вложений и ссылок программами по умолчанию |
| `libgssapi-krb5-2` | Вход в Exchange по Kerberos (единый вход в домене ALD Pro / FreeIPA / Samba AD) |

Это рекомендуемые зависимости: `apt` ставит их по умолчанию.

## Вход в Exchange

- **По паролю**: NTLM работает без дополнительных пакетов, в программе используется встроенная реализация .NET.
- **Без пароля, единый вход**: если компьютер в домене и у пользователя есть билет Kerberos (вход в систему
  доменной учётной записью или `kinit`), оставьте пароль пустым и выберите «Kerberos (Negotiate)».
- **Корпоративный удостоверяющий центр** или «Russian Trusted Root CA»: корневой сертификат указывается в
  настройках учётной записи. Его можно также задать политикой (см. ниже).

## Централизованная настройка

Это аналог групповых политик Windows: файл `/etc/mailclient/policy.json` с теми же параметрами
(`EwsUrl`, `Domain`, `EmailDomain`, `AuthMethod`, `ServerVersion`, `TrustedRootCertificateFile`,
`LockServerSettings`, `Protocol`, `ImapHost`, `ImapPort`, `SmtpHost`, `SmtpPort`, `DisableForwardingRules`).
Пример лежит в `/usr/share/doc/mailclient/policy.example.json`. Файл раскладывается средствами ALD Pro,
Ansible или Astra Automation и читается при запуске программы.

## Замкнутая программная среда (ЗПС)

В режиме ЗПС запускаются только подписанные ELF-файлы. Пакет не собран в один файл: программа и нативные
библиотеки лежат отдельными файлами в `/opt/mailclient`, и каждую можно подписать.

- Для своих компьютеров: на машине Astra Linux с утилитой `bsign` и ключом организации выполните
  `sudo packaging/linux/sign-zps.sh /opt/mailclient`. Открытый ключ должен быть установлен на рабочих местах
  администратором. В Astra Linux SE 1.8 для этого есть также `bsign-integrator`.
- Для поставки в аттестованные системы нужна подпись ГК «Астра» по программе «Ready for Astra».

Сценарий подписи на настоящей Astra Linux ещё не проверялся. Это нужно сделать на стенде до внедрения.

## Данные

| Что | Где |
|---|---|
| Настройки | `~/.config/MailClient/settings.json` |
| Пароли (если нет хранилища ключей) | `~/.config/MailClient/secrets` (права 0700/0600, AES-GCM) |
| Кэш писем, журналы | `~/.local/share/MailClient` |

## Что есть и чего пока нет

Есть:
- учётные записи Exchange и IMAP/SMTP с автообнаружением и проверкой входа (одна попытка);
- папки со счётчиками непрочитанных, создание, переименование и удаление папок;
- список писем с поиском (на сервере, без связи — по кэшу);
- просмотр писем: блокировка внешних изображений, вложения, приглашения на встречи;
- ответ, ответ всем, пересылка, черновики;
- редактор с шрифтами, размерами, начертанием и списками;
- перемещение, удаление, флажки, отметка «прочитано»;
- уведомления о новых письмах, один экземпляр программы и обработка `mailto:`.

Пока только в версии для Windows:
- автоответы;
- правила пересылки;
- личные контакты и карточки контактов;
- окно параметров программы;
- перетаскивание писем мышью;
- значок в области уведомлений.

## Сборка

```bash
export AVALONIA_TELEMETRY_OPTOUT=1        # не отправлять статистику сборки Avalonia
dotnet test --project tests/MailClient.Linux.Tests
dotnet publish src/MailClient.Linux -c Release -r linux-x64 --self-contained true -p:Version=1.0.0 -o publish/linux-x64
bash packaging/linux/build-deb.sh 1.0.0 publish/linux-x64 publish
```
